TypeScript SDK Reference

The @osd/dashboards-sdk package provides strongly-typed, fluent builders for defining OpenSearch Dashboards resources as code. Definitions compile to JSON or YAML files suitable for version control and deployment via osdctl apply.

Installation


npm install @osd/dashboards-sdk

The SDK requires TypeScript 4.7 or later (or plain JavaScript with ES2020+ support).

Imports


import {
  Dashboard,
  Panel,
  Query,
  DataSource,
  Variable,
} from '@osd/dashboards-sdk';

Dashboard Builder

The Dashboard class is the top-level builder. It produces a DashboardDefinition with the dashboards.opensearch.org/v1alpha1 API version.

Creating a Dashboard


const dashboard = Dashboard.create('my-dashboard-name');

The name is the unique resource identifier. It must be a stable, URL-safe string (kebab-case recommended). This becomes the saved object ID.

Methods

MethodSignatureDescription
createstatic create(name: string): DashboardFactory method. Creates a new builder instance.
titletitle(title: string): DashboardSets the display title shown in the UI.
descriptiondescription(desc: string): DashboardSets the dashboard description.
labelslabels(labels: Record<string, string>): DashboardSets metadata labels for filtering and organization. Merges with existing labels.
annotationannotation(key: string, value: string): DashboardAdds a single annotation (free-form metadata).
timeRangetimeRange(from: string, to: string): DashboardSets the default time range (e.g., 'now-1h', 'now').
refreshIntervalrefreshInterval(interval: string): DashboardSets the auto-refresh interval (e.g., '30s', '1m', '5m').
addPaneladdPanel(panel: Panel): DashboardAdds a panel to the dashboard.
addDataSourceaddDataSource(dataSource: DataSource): DashboardAdds a data source reference.
addVariableaddVariable(variable: Variable): DashboardAdds a template variable.
buildbuild(): DashboardDefinitionCompiles and returns the full definition object.
toJSONtoJSON(filepath?: string): stringSerializes to JSON. If filepath is provided, writes to file. Returns the JSON string.
toYAMLtoYAML(filepath?: string): stringSerializes to YAML. If filepath is provided, writes to file. Returns the YAML string.

Example


const dashboard = Dashboard.create('web-traffic')
  .title('Web Traffic Overview')
  .description('HTTP request metrics for all web servers')
  .labels({ env: 'production', team: 'platform', tier: 'frontend' })
  .annotation('owner', 'platform-team@company.com')
  .annotation('source-repo', 'github.com/acme/dashboards')
  .timeRange('now-6h', 'now')
  .refreshInterval('1m')
  .addVariable(
    Variable.create('cluster')
      .type('custom')
      .label('Cluster')
      .options(['us-east-1', 'us-west-2', 'eu-west-1'])
      .defaultValue('us-east-1')
  )
  .addPanel(
    Panel.create('total-requests')
      .visualization('metric')
      .gridPosition({ x: 0, y: 0, w: 8, h: 6 })
      .query(Query.ppl("source = access_logs | stats count() as total"))
  )
  .addDataSource(
    DataSource.create('logs-cluster').type('opensearch').default(true)
  );

// Write to file
dashboard.toYAML('built/web-traffic.yaml');

Output Structure

The build() method returns a DashboardDefinition with this shape:


interface DashboardDefinition {
  apiVersion: string;          // 'dashboards.opensearch.org/v1alpha1'
  kind: string;                // 'Dashboard'
  metadata: {
    name: string;              // Resource identifier
    labels: Record<string, string>;
    annotations: Record<string, string>;
  };
  spec: {
    title: string;
    description: string;
    timeRange?: { from: string; to: string };
    refreshInterval?: string;
    panels: PanelDefinition[];
    dataSources: DataSourceDefinition[];
    variables: VariableDefinition[];
  };
}

Panel Builder

The Panel class builds individual visualization panels within a dashboard.

Creating a Panel


const panel = Panel.create('my-panel-name');

The name is a unique identifier within the dashboard.

Methods

MethodSignatureDescription
createstatic create(name: string): PanelFactory method. Creates a new panel builder.
visualizationvisualization(type: VisualizationType): PanelSets the visualization type. Default: 'line'.
gridPositiongridPosition(pos: GridPosition): PanelSets the panel position and size in the grid layout.
queryquery(q: Query): PanelSets the data query for this panel.
optionoption(key: string, value: unknown): PanelSets a visualization-specific option.
buildbuild(): PanelDefinitionCompiles and returns the panel definition.

Visualization Types

The VisualizationType union supports:

TypeDescription
'line'Line chart for time-series data
'bar'Bar chart for categorical comparisons
'area'Area chart (filled line chart)
'pie'Pie or donut chart
'heatmap'Heatmap for density visualization
'table'Tabular data display
'metric'Single-value metric display
'gauge'Gauge chart for threshold visualization
'markdown'Static markdown content panel

Grid Position

The dashboard uses a 48-column grid layout. Each panel has:

PropertyTypeDescription
xnumberHorizontal position (0-47)
ynumberVertical position (rows from top)
wnumberWidth in grid columns (1-48)
hnumberHeight in grid rows

Default grid position is { x: 0, y: 0, w: 12, h: 8 }.

Query Builder

The Query class provides static factory methods for each supported query language.

Factory Methods

MethodSignatureDescription
Query.pplstatic ppl(query: string): QueryCreates a PPL (Piped Processing Language) query.
Query.dqlstatic dql(query: string): QueryCreates a DQL (Dashboards Query Language) query.
Query.sqlstatic sql(query: string): QueryCreates a SQL query.
Query.lucenestatic lucene(query: string): QueryCreates a Lucene query.

All factory methods throw an error if the query string is empty or whitespace-only.

The build() method returns a QueryDefinition:


interface QueryDefinition {
  language: 'PPL' | 'DQL' | 'SQL' | 'Lucene';
  query: string;
}

PPL Examples

PPL (Piped Processing Language) is OpenSearch's native pipeline query language:


// Basic aggregation
Query.ppl("source = metrics | stats avg(cpu_percent) by host")

// Time-series with bucketing
Query.ppl("source = metrics | stats avg(value) by span(timestamp, 5m)")

// Filtering and sorting
Query.ppl("source = logs | where level = 'ERROR' | sort - timestamp | head 100")

// Multiple aggregations
Query.ppl("source = web_logs | stats count() as total, avg(latency_ms) as avg_lat, p99(latency_ms) as p99_lat by endpoint")

// Using variables (template variable substitution)
Query.ppl("source = metrics | where host = '$host' and cluster = '$cluster' | stats avg(cpu) by span(timestamp, 1m)")

DQL Examples

DQL (Dashboards Query Language) is the search-bar query syntax:


// Simple field match
Query.dql("status:200")

// Boolean operators
Query.dql("level:error AND service:payment-api")

// Wildcard
Query.dql("host:web-*")

// Range
Query.dql("response_time > 500")

// Nested fields
Query.dql("kubernetes.pod.name:api-server-*")

SQL Examples


// Standard SQL aggregation
Query.sql("SELECT host, AVG(cpu_percent) as avg_cpu FROM metrics GROUP BY host ORDER BY avg_cpu DESC")

// Join across indices
Query.sql("SELECT a.endpoint, a.avg_latency, b.error_count FROM (SELECT endpoint, AVG(latency) as avg_latency FROM access_logs GROUP BY endpoint) a LEFT JOIN (SELECT endpoint, COUNT(*) as error_count FROM error_logs GROUP BY endpoint) b ON a.endpoint = b.endpoint")

// Window functions
Query.sql("SELECT host, cpu_percent, timestamp, AVG(cpu_percent) OVER (PARTITION BY host ORDER BY timestamp ROWS BETWEEN 5 PRECEDING AND CURRENT ROW) as moving_avg FROM metrics")

Lucene Examples


// Full-text search
Query.lucene("connection refused")

// Field-specific search
Query.lucene("message:\"out of memory\" AND level:ERROR")

// Regex
Query.lucene("host:/web-[0-9]+/")

// Fuzzy search
Query.lucene("message:errror~2")

Serialization

toJSON


// Write to file
const json = dashboard.toJSON('built/my-dashboard.json');

// Get string only (no file written)
const json = dashboard.toJSON();
console.log(json);

JSON output uses sorted keys and 2-space indentation for deterministic, diff-friendly output.

toYAML


// Write to file
const yaml = dashboard.toYAML('built/my-dashboard.yaml');

// Get string only
const yaml = dashboard.toYAML();
console.log(yaml);

YAML is the recommended format for version control because it produces cleaner diffs.

Validation

The SDK performs client-side validation when calling build(). Validation checks include:

  • Required fields (title, panels) are present
  • Panel names are unique within a dashboard
  • Grid positions have valid values (w >= 1, h >= 1)
  • Query strings are non-empty
  • Variable names are unique

For server-side validation (checking data source existence, plugin availability), use osdctl validate --server. See the CLI Reference.

Reusable Components Pattern

One of the most powerful aspects of defining dashboards in code is the ability to create reusable, parameterized components.

Shared Panel Templates

Create a shared library of panel templates:


// shared/panels.ts
import { Panel, Query } from '@osd/dashboards-sdk';

/**
 * Creates a standard CPU usage line chart.
 */
export function cpuPanel(name: string, filter?: string): Panel {
  const whereClause = filter ? `| where ${filter}` : '';
  return Panel.create(name)
    .visualization('line')
    .gridPosition({ x: 0, y: 0, w: 24, h: 12 })
    .query(
      Query.ppl(`source = metrics ${whereClause} | stats avg(cpu_percent) by span(timestamp, 1m), host`)
    )
    .option('showLegend', true)
    .option('yAxisLabel', 'CPU %');
}

/**
 * Creates a standard memory usage gauge.
 */
export function memoryGauge(name: string, filter?: string): Panel {
  const whereClause = filter ? `| where ${filter}` : '';
  return Panel.create(name)
    .visualization('gauge')
    .gridPosition({ x: 0, y: 0, w: 8, h: 8 })
    .query(
      Query.ppl(`source = metrics ${whereClause} | stats avg(memory_used_percent) as usage`)
    )
    .option('min', 0)
    .option('max', 100)
    .option('thresholds', [
      { value: 0, color: 'green' },
      { value: 70, color: 'yellow' },
      { value: 90, color: 'red' },
    ]);
}

/**
 * Creates a standard error log table.
 */
export function errorTable(name: string, source: string): Panel {
  return Panel.create(name)
    .visualization('table')
    .gridPosition({ x: 0, y: 0, w: 24, h: 10 })
    .query(
      Query.ppl(`source = ${source} | where level = 'ERROR' | sort - timestamp | head 50`)
    )
    .option('showPagination', true);
}

Using Shared Panels


// dashboards/web-server.ts
import { Dashboard, DataSource } from '@osd/dashboards-sdk';
import { cpuPanel, memoryGauge, errorTable } from '../shared/panels';

Dashboard.create('web-server-monitoring')
  .title('Web Server Monitoring')
  .description('CPU, memory, and error monitoring for web servers')
  .labels({ env: 'production', team: 'platform', service: 'web' })
  .timeRange('now-1h', 'now')
  .refreshInterval('30s')
  .addPanel(cpuPanel('web-cpu', "service = 'web'"))
  .addPanel(memoryGauge('web-memory', "service = 'web'"))
  .addPanel(errorTable('web-errors', 'web_server_logs'))
  .addDataSource(DataSource.create('metrics').type('opensearch').default(true))
  .toYAML('built/web-server-monitoring.yaml');

Kubernetes Monitoring Dashboard


import { Dashboard, Panel, Query, DataSource, Variable } from '@osd/dashboards-sdk';

const k8sDashboard = Dashboard.create('kubernetes-cluster-overview')
  .title('Kubernetes Cluster Overview')
  .description('Pod, node, and container metrics for Kubernetes clusters')
  .labels({ env: 'production', team: 'infrastructure', domain: 'kubernetes' })
  .annotation('owner', 'infra-team@company.com')
  .timeRange('now-3h', 'now')
  .refreshInterval('30s')
  .addVariable(
    Variable.create('namespace')
      .type('query')
      .label('Namespace')
      .query("source = k8s_metrics | dedup namespace | fields namespace")
      .multi(true)
  )
  .addVariable(
    Variable.create('node')
      .type('query')
      .label('Node')
      .query("source = k8s_metrics | dedup node | fields node")
      .multi(true)
  )
  // Row 1: Cluster summary metrics
  .addPanel(
    Panel.create('total-pods')
      .visualization('metric')
      .gridPosition({ x: 0, y: 0, w: 8, h: 6 })
      .query(Query.ppl("source = k8s_metrics | where metric = 'pod_count' | stats sum(value) as total_pods"))
  )
  .addPanel(
    Panel.create('running-pods')
      .visualization('metric')
      .gridPosition({ x: 8, y: 0, w: 8, h: 6 })
      .query(Query.ppl("source = k8s_metrics | where metric = 'pod_count' and status = 'Running' | stats sum(value) as running"))
  )
  .addPanel(
    Panel.create('failed-pods')
      .visualization('metric')
      .gridPosition({ x: 16, y: 0, w: 8, h: 6 })
      .query(Query.ppl("source = k8s_metrics | where metric = 'pod_count' and status = 'Failed' | stats sum(value) as failed"))
      .option('colorMode', 'background')
      .option('thresholds', [{ value: 0, color: 'green' }, { value: 1, color: 'red' }])
  )
  // Row 2: CPU and memory
  .addPanel(
    Panel.create('node-cpu')
      .visualization('line')
      .gridPosition({ x: 0, y: 6, w: 24, h: 12 })
      .query(Query.ppl("source = k8s_metrics | where metric = 'node_cpu_percent' and namespace IN ($namespace) | stats avg(value) by span(timestamp, 1m), node"))
      .option('showLegend', true)
      .option('yAxisLabel', 'CPU %')
  )
  .addPanel(
    Panel.create('node-memory')
      .visualization('line')
      .gridPosition({ x: 24, y: 6, w: 24, h: 12 })
      .query(Query.ppl("source = k8s_metrics | where metric = 'node_memory_percent' and namespace IN ($namespace) | stats avg(value) by span(timestamp, 1m), node"))
      .option('showLegend', true)
      .option('yAxisLabel', 'Memory %')
  )
  // Row 3: Pod restart table
  .addPanel(
    Panel.create('pod-restarts')
      .visualization('table')
      .gridPosition({ x: 0, y: 18, w: 48, h: 10 })
      .query(Query.ppl("source = k8s_events | where reason = 'Restarted' | stats count() as restarts by pod, namespace | sort - restarts | head 20"))
  )
  .addDataSource(DataSource.create('k8s-metrics').type('opensearch').default(true));

import { Dashboard, Panel, Query, DataSource, Variable } from '@osd/dashboards-sdk';

const apmDashboard = Dashboard.create('application-performance')

      .visualization('line')
      .gridPosition({ x: 0, y: 6, w: 24, h: 12 })

Log Analysis Dashboard

  )
  .addDataSource(DataSource.create('logs').type('opensearch').default(true));

logsDashboard.toYAML('built/log-analysis.yaml');
